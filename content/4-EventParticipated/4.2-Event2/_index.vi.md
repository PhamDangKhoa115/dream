## Nội dung chính

### 1. Dự án AIoT – Hệ thống tủ thông minh

#### Vấn đề

- Quy trình mượn đồ còn thủ công và thiếu hiệu quả
- Phụ thuộc vào người quản lý
- Thiếu tính tự động và khả năng theo dõi

#### Giải pháp

- Sử dụng **Arduino, Raspberry Pi và các cảm biến**
- Kết nối thiết bị với cloud thông qua **AWS IoT Core**
- Ứng dụng **Amazon Rekognition** để nhận diện khuôn mặt

#### Kiến trúc hệ thống

- **Amazon S3** → lưu trữ hình ảnh
- **DynamoDB** → lưu thông tin người dùng
- **AWS Lambda** → xử lý logic và AI
- **AWS Amplify** → triển khai giao diện web

---

### 2. AI Agents và Strands Framework

#### AI Agent là gì?

AI Agent là một hệ thống có khả năng:

- Thực hiện suy luận nhiều bước
- Tương tác với API và các công cụ bên ngoài
- Tự động ra quyết định và hành động
- Truy cập dữ liệu theo thời gian thực
- Thích ứng theo ngữ cảnh

#### Strands Agent

Framework Strands giúp:

- Xây dựng AI Agent dễ dàng hơn
- Tích hợp các công cụ như API và database
- Tạo các workflow tự động

---

### 3. Prompt Engineering

#### Các vấn đề thường gặp

- Prompt không rõ ràng → kết quả kém
- Tốn nhiều token → chi phí cao
- Kết quả không ổn định

#### Thành phần của một prompt tốt

- Role (vai trò)
- Instruction (yêu cầu)
- Context (ngữ cảnh)
- Input data
- Output format
- Constraints (ràng buộc)

#### Kỹ thuật nâng cao

- Chain-of-Thought prompting
- Role prompting
- Retrieval-Augmented Generation (RAG)
