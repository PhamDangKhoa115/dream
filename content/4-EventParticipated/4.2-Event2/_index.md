## Event Description

- Prompt Engineering for working with large language models

---

## Main Content

### 1. AIoT Project – Smart Locker System

#### Problem

- Manual and inefficient borrowing process
- Dependence on a manager
- Lack of automation and tracking

#### Solution

- Use **Arduino, Raspberry Pi, and sensors**
- Connect devices through **AWS IoT Core**
- Apply **Amazon Rekognition** for facial recognition

#### System Architecture

- **Amazon S3** → store images
- **DynamoDB** → store user information
- **AWS Lambda** → process logic and AI tasks
- **AWS Amplify** → host the web interface

---

### 2. AI Agents and Strands Framework

#### What is an AI Agent?

An AI Agent is a system that can:

- Perform multi-step reasoning
- Interact with APIs and external tools
- Make decisions and take actions
- Access real-time data
- Adapt based on context

#### Strands Agent

The Strands framework helps:

- Build AI agents more easily
- Integrate tools such as APIs and databases
- Create automated workflows

---

### 3. Prompt Engineering

#### Common Problems

- Vague prompts → poor output
- High token usage → increased cost
- Inconsistent responses

#### Components of a Good Prompt

- Role
- Instruction
- Context
- Input data
- Output format
- Constraints

#### Advanced Techniques

- Chain-of-Thought prompting
- Role prompting
- Retrieval-Augmented Generation (RAG)
