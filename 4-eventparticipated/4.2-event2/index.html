Event 2: AIoT Projects, AI Agents and Prompt Engineering

Event Information

  • Event Name: AIoT Projects, AI Agents & Prompt Engineering Workshop
  • **Date & Time:**9 a.m March 14th
  • **Location:**26th Floor, Bitexco Tower, 02 Hai Trieu Street, Saigon Ward, Ho Chi Minh City
  • Role: Attendee

Speaker

  • Anh Dinh Le Hoang – AI Engineer
  • Vinh Banh Cam – Data Engineer
  • Thinh Nguyen Tuan – DevOps Engineer

Event Description

This event focused on three important topics in modern technology:

  • AI combined with IoT (AIoT)
  • AI Agents and autonomous systems
  • Prompt Engineering for working with large language models

Main Content

1. AIoT Project – Smart Locker System

Problem

  • Manual and inefficient borrowing process
  • Dependence on a manager
  • Lack of automation and tracking

Solution

  • Use Arduino, Raspberry Pi, and sensors
  • Connect devices through AWS IoT Core
  • Apply Amazon Rekognition for facial recognition

System Architecture

  • Amazon S3 → store images
  • DynamoDB → store user information
  • AWS Lambda → process logic and AI tasks
  • AWS Amplify → host the web interface

2. AI Agents and Strands Framework

What is an AI Agent?

An AI Agent is a system that can:

  • Perform multi-step reasoning
  • Interact with APIs and external tools
  • Make decisions and take actions
  • Access real-time data
  • Adapt based on context

Strands Agent

The Strands framework helps:

  • Build AI agents more easily
  • Integrate tools such as APIs and databases
  • Create automated workflows

3. Prompt Engineering

Common Problems

  • Vague prompts → poor output
  • High token usage → increased cost
  • Inconsistent responses

Components of a Good Prompt

  • Role
  • Instruction
  • Context
  • Input data
  • Output format
  • Constraints

Advanced Techniques

  • Chain-of-Thought prompting
  • Role prompting
  • Retrieval-Augmented Generation (RAG)

Key Takeaways

From this event, I learned that:

  • AI can be combined with IoT to build smart systems
  • AI Agents represent a more advanced use of LLMs
  • Prompt Engineering is essential for optimizing AI performance
  • AWS provides a complete ecosystem for building AI applications

Personal Experience

This event gave me a broader understanding of how AI technologies are applied in real-world scenarios.

I was particularly interested in how AI can interact with physical devices through IoT systems and automate workflows.And also am interested in how to how easy to host using Amplify and how Rag can improve my project.

Additionally, the Prompt Engineering section helped me understand how to work more effectively with AI tools, which is highly relevant to my current project.

Conclusion

This event provided a comprehensive overview of modern technologies such as AIoT, AI Agents, and Prompt Engineering.

It helped me better understand how to design intelligent systems and apply AI solutions in cloud-based environments.
